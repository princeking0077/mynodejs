📊 COMPONENT HIERARCHY
======================

App.jsx
├─ AdminLogin (when not logged in)
└─ AdminDashboard (when logged in)
   └─ AdminLayout
      ├─ AdminSidebar
      └─ Children (one of these):
         ├─ DashboardOverview
         └─ ContentEditor


🎨 WHAT EACH COMPONENT DOES
============================

AdminLogin.jsx
- Beautiful glassmorphism login card
- Animated gradient background
- Email/password form
- Error display
- Validates: admin@example.com / admin123

AdminDashboard.jsx
- Manages view state (overview/editor)
- Handles context selection (which subject is open)
- Coordinates between components

AdminLayout.jsx
- Contains the sidebar
- Top navigation bar with breadcrumbs
- Search bar (desktop)
- Notification button
- Mobile menu toggle

AdminSidebar.jsx
- Logo & brand
- "Overview" button
- Expandable year/semester/subject tree
- User profile section
- Logout button

DashboardOverview.jsx
- 4 stat cards (Users, Content, Quizzes, Uptime)
- 4 year progress cards
- Shows subject counts
- Progress bars

ContentEditor.jsx
- Existing topics sidebar (left)
- Main editor form (right):
  * Basic info (title, YouTube ID)
  * Blog content (textarea with toolbar)
  * SEO metadata (meta title, description, keywords)
  * Quiz question builder
  * File upload dropzone

🎨 STYLING SYSTEM
=================

All styles use Tailwind CSS via CDN + custom classes in App.css

Custom Classes:
- .glass-panel          → Glassmorphism effect
- .glow-primary         → Glowing shadow
- .bg-gradient-animated → Animated gradient background
- .input-glow           → Focus glow effect
- .card-hover           → Hover lift effect
- .tab-active           → Active tab styling
- .badge-*              → Badge variants
- .custom-scrollbar     → Custom scrollbar
- .admin-scope          → Typography guard
